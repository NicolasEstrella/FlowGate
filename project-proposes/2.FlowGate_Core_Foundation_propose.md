# Proposal 2 - FlowGate Core Foundation

## Repositorio alvo

FlowGate.Core

## Objetivo

Transformar a API base atual em uma fundacao de backend orientada ao dominio, pronta para suportar workflow, auditoria, RBAC e persistencia real em PostgreSQL.

## Base documental

- `docs/01-overview.md`
- `docs/02-architecture.md`
- `docs/04-features.md`

## Escopo

- Remover o exemplo padrao de WeatherForecast e substituir pela estrutura inicial do dominio FlowGate.
- Introduzir entidades e agregados base como Workflow, WorkflowInstance, ApprovalStep, AuditLog e User.
- Configurar EF Core com PostgreSQL, `DbContext`, mapeamentos e primeira migration coerente com a arquitetura de dados.
- Criar camadas ou organizacao interna clara para API, dominio, aplicacao e infraestrutura.
- Implementar middlewares basicos para tratamento de erros, logging estruturado e correlacao de requisicoes.
- Preparar autenticacao/autorizacao inicial com RBAC compativel com Admin, Aprovador, Financeiro, Juridico e Usuario Comum.
- Expor endpoints iniciais de health check, usuarios, workflows e instancias em nivel de fundacao.

## Entregas esperadas

- Backend sem codigo de template.
- Persistencia funcional no Postgres.
- Seed ou mecanismo simples para papeis basicos de acesso.
- Padrao de resposta de erro e validacao consistente.
- Estrutura pronta para crescer sem reescrita arquitetural.

## Criterios de aceite

- O projeto sobe localmente conectado ao banco provisionado pela infra.
- Existe migration inicial aplicavel em ambiente limpo.
- Os principais recursos do dominio possuem modelos persistidos e versionaveis.
- Auditoria e autorizacao ja possuem pontos de extensao definidos.
- A API fica pronta para receber a implementacao do engine sem refatoracao estrutural grande.

## Dependencias

- `1.FlowGate_Infra_Foundation_propose.md`

## Fora de escopo

- Execucao completa do workflow.
- Rule engine dinamico.
- Mensageria e workers.
- Geração real de documentos.

## Sugestao de nome OpenSpec

`build-core-domain-foundation`

## Prompt sugerido

Criar a fundacao do backend em `FlowGate.Core`, substituindo o template atual por uma API de dominio alinhada ao FlowGate. A implementacao deve incluir entidades principais, EF Core com PostgreSQL, migration inicial, organizacao arquitetural clara, middlewares transversais, RBAC basico e endpoints de fundacao para workflows, instancias, usuarios e health checks.
