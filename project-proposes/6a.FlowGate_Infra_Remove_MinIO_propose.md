# Proposal 6a - FlowGate Infra: Remove MinIO, Adopt Local Volume Storage

> **Emergencial** — deve ser executado antes do Proposal 6 (Async Automation Layer).

## Repositorio alvo

FlowGate.Infra / FlowGate.Core

## Objetivo

Remover o MinIO do ambiente de infraestrutura e substituir por volume local Docker para armazenamento de documentos gerados (PDFs, comprovantes). A aplicacao roda exclusivamente em ambiente local de desenvolvimento, tornando um object storage S3-compatible desnecessario e oneroso.

## Base documental

- `docs/02-architecture.md` (ja atualizado)
- `docs/04-features.md` (ja atualizado)

## Escopo

### FlowGate.Infra (docker-compose.yml)

- Remover o servico `minio` do compose.
- Remover as variaveis de ambiente `MINIO_*` do `.env.example`.
- Adicionar volume nomeado `documents_data` para persistencia de documentos.
- Montar o volume `documents_data` no servico `backend` em `/app/documents`.
- Remover dependencia do `minio` do servico `backend`.
- Atualizar o README de infra documentando o novo modelo de armazenamento.

### FlowGate.Core (appsettings)

- Adicionar configuracao `Storage:DocumentsPath` apontando para `/app/documents` (Docker) ou um caminho local configuravel.
- Remover quaisquer referencias a `MinIO` em `appsettings.json` e `appsettings.Development.json`.

## Entregas esperadas

- Compose funcional sem MinIO, com volume local para documentos.
- Path de armazenamento configuravel via `appsettings`.
- README de infra atualizado refletindo o novo modelo.
- Sem quebra de compatibilidade com os servicos restantes (Postgres, RabbitMQ, Redis).

## Criterios de aceite

- O ambiente sobe com `docker compose up -d` sem o servico MinIO.
- O backend consegue escrever e ler arquivos no volume montado.
- O path de documentos e configuravel sem alteracao de codigo.
- Volumes de Postgres, RabbitMQ e Redis continuam funcionando normalmente.
- O `.env.example` nao tem mais variaveis de MinIO.

## Dependencias

## Fora de escopo

- Migracao de dados existentes no MinIO (nao ha dados de producao).
- SDK de MinIO no backend (nunca foi integrado).
- Integracao com provedores externos de armazenamento.
