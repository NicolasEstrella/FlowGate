# Proposal 1 - FlowGate Infra Foundation

## Repositorio alvo

FlowGate.Infra

## Objetivo

Criar a base de infraestrutura local do FlowGate para sustentar o desenvolvimento do backend e do portal com servicos alinhados a arquitetura definida nos docs.

## Base documental

- `docs/02-architecture.md`
- `docs/03-workflow-engine.md`
- `docs/04-features.md`

## Escopo

- Expandir o `docker-compose.yml` para incluir PostgreSQL, RabbitMQ, Redis, MinIO, backend, portal e gateway NGINX.
- Definir redes, volumes nomeados e health checks para todos os servicos essenciais.
- Padronizar variaveis de ambiente e arquivos `.env.example` para desenvolvimento local.
- Garantir ordem de subida coerente para que API e portal dependam apenas de servicos saudaveis.
- Expor URLs e portas consistentes com a documentacao do projeto.
- Atualizar o README de infra com fluxo de bootstrap, reset e troubleshooting basico.

## Entregas esperadas

- Compose funcional com todos os blocos da arquitetura principal.
- Volume persistente para Postgres, RabbitMQ e MinIO.
- Credenciais de desenvolvimento claramente documentadas.
- Gateway com roteamento inicial entre portal e API.
- Health checks suficientes para validar subida local.

## Criterios de aceite

- Um unico comando sobe o ambiente local completo.
- API consegue conectar no Postgres sem ajustes manuais apos o bootstrap.
- RabbitMQ, Redis e MinIO ficam acessiveis para o backend.
- Portal e API ficam disponiveis por portas previsiveis e documentadas.
- O ambiente pode ser derrubado e recriado sem passos ocultos.

## Dependencias

- Nenhuma. Esta proposta abre a sequencia.

## Fora de escopo

- Observabilidade avancada.
- Pipelines de CI/CD.
- Segredos para producao.
- TLS real e configuracoes multiambiente complexas.

## Sugestao de nome OpenSpec

`establish-infra-foundation`

## Prompt sugerido

Criar a base de infraestrutura local do FlowGate em `FlowGate.Infra`, expandindo o `docker-compose.yml` para refletir a arquitetura do projeto com PostgreSQL, RabbitMQ, Redis, MinIO, backend, portal e NGINX. O resultado deve deixar o ambiente de desenvolvimento pronto para as proximas fases, com variaveis de ambiente padronizadas, health checks, volumes persistentes, roteamento inicial e documentacao suficiente para bootstrap local.
