# Proposal 3 - FlowGate Portal Foundation

## Repositorio alvo

FlowGate.Portal

## Objetivo

Criar a base do portal web para que o front deixe de ser apenas um scaffold Angular e passe a representar a experiencia principal do produto.

## Base documental

- `docs/01-overview.md`
- `docs/02-architecture.md`
- `docs/04-features.md`
- `docs/05-use-cases.md`

## Escopo

- Estruturar layout principal com shell autenticado, cabecalho, navegacao lateral e areas por papel.
- Configurar rotas, guards e servicos de autenticacao/autorizacao compatveis com RBAC do projeto.
- Criar camada de integracao HTTP com ambientes, interceptadores e tratamento padrao de erros.
- Definir design tokens e componentes compartilhados para cards, tabelas, status chips, loaders e estados vazios.
- Criar dashboard inicial para Usuario Comum e Admin com visao resumida de solicitacoes e pendencias.
- Preparar a base para consumo de endpoints futuros de workflows, aprovacoes, auditoria e documentos.

## Entregas esperadas

- Casca de aplicacao responsiva.
- Navegacao consistente por modulos principais.
- Estrutura clara de pastas para componentes, paginas, servicos e modelos.
- Fluxo basico de sessao local ou autenticacao simulada controlada por ambiente.
- Integração preparada para a API do backend.

## Criterios de aceite

- O portal possui identidade visual minima coerente com um sistema corporativo.
- As rotas principais estao protegidas por guards.
- O app consegue apontar para ambientes locais sem ajustes manuais espalhados.
- Estados de carregamento, erro e vazio estao previstos nos componentes base.
- A estrutura front fica pronta para receber as telas operacionais nas proximas fases.

## Dependencias

- `1.FlowGate_Infra_Foundation_propose.md`
- `2.FlowGate_Core_Foundation_propose.md`

## Fora de escopo

- Form builder de workflow.
- Inbox operacional completa.
- Timeline detalhada de auditoria.
- Painel administrativo avancado.

## Sugestao de nome OpenSpec

`build-portal-foundation`

## Prompt sugerido

Criar a fundacao do portal em `FlowGate.Portal`, transformando o scaffold Angular atual em uma SPA com shell autenticado, layout corporativo, rotas protegidas, camada HTTP, componentes base reutilizaveis e dashboards iniciais por papel. A solucao deve preparar o front para consumir o backend do FlowGate nas proximas etapas sem reestruturar a aplicacao.
